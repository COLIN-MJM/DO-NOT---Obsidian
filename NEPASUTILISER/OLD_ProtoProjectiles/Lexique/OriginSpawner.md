L'[[OriginSpawner]] est un point fixe dans l'espace à partir duquel sont instanciés tous les [[Projectiles]].
- Si le [[Joueur - 3Cs]] effectue un input simple, il est instancié depuis le Forward de l'[[OriginSpawner]]
-  Si le [[Joueur - 3Cs]] effectue un input avec Shift, 8 [[Projectiles]] sont instanciés de façon équidistante à partir de l'[[OriginSpawner]].
